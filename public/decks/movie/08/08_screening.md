# 上映の進め方：提出フォルダの名前の順に、1人2分

- 提出フォルダに入っている作品を上映します。上映の途中で入った作品は、最後に上映します
- 順番は、提出フォルダの中の自分のクラス（1D1・1D2）のフォルダに並ぶ、名前の順（学籍番号の順）です。提出フォルダは、Classroomの「第8週資料」の【提出場所】から開けます

# 発表：作品意図と工夫したところを、30秒で話しましょう

提出したGoogleドキュメントの【作品意図】をもとに、前に出て、次の順で話してください

| 順 | 話すこと | 例 |
|---|---|---|
| 1 | 名前 | 〇〇です |
| 2 | だれに見てほしいか | 京都に遊びに来た20代の観光客に見てほしいです |
| 3 | 見た人にどう思ってほしいか | 二条駅のすぐ近くに昭和の街並みがあると知って、行ってみたくなってほしいです |
| 4 | 工夫したところ（1〜2つ） | 入口から奥へ歩く順にカットを並べ、曲の小節の頭で切り替えました |

- 30秒で話せるのは、文字にするとおよそ150字です
- 操作で苦労したことより、見る人に向けて工夫したことを話しましょう

# 講評：自分の学籍番号のすぐ後の2人の作品に書きましょう

1. Classroomの授業タブで、課題「第8週相互講評」を開きます
2. 提出フォルダの並びで、**自分の学籍番号のすぐ後にある2人** の作品を見ながら、それぞれ次の3つを書きます
   - 作品の学籍番号
   - よかったところ
   - もっとよくなるところと、そのための案
3. 2人分を書いたら、**1講時が終わるまでに** 送信します

- 自分の後に2人いないときは、並びの最初に戻ります（例：最後の人は、1番目と2番目の人に書きます）
- 作品を提出していない人も、同じ決め方で2人に書いてください
- 作者には、だれが書いた講評かは見えません（先生には見えます）

# 講評は、場面を指して具体的に書きましょう

| | 伝わりにくい書き方 | 伝わる書き方 |
|---|---|---|
| よかったところ | よかったです | 最初の3秒で店の入口へ歩いていくので、続きを見たくなりました |
| もっとよくなるところ | テロップが見づらい | 10秒あたりの白い壁のカットで、白い文字が読みにくいです。境界線を付けると読みやすくなりそうです |

- 「何秒あたりの、どのカットで、何が、どうだったか」を書きます
- もっとよくなるところには、どうすればよくなるかの案も書きましょう

見るところの例

- 作品意図（だれに・どう思ってほしいか）が伝わるか
- テロップが、スマホで読める大きさと長さか
- 曲の大きさと、スマホで撮った音や効果音の聞こえ方
- カットの長さと、曲の区切りとの合い方

# 自分の作品への講評を読み、直すところを決めましょう

1. Classroomの授業タブで「第8週資料」を開き、【講評まとめ】のリンクを開きます
2. <kbd>Ctrl</kbd>+<kbd>F</kbd> で自分の学籍番号を探し、自分の作品への講評をすべて読みます
3. 直すところを1〜3つ決めて、メモします。迷ったら、次の順で選んでください

| 順 | 直すところ | 例 |
|---|---|---|
| 1 | 提出前のチェックリストにかかわるところ | テロップがキャプションの位置にかかる、曲が大きすぎる |
| 2 | 作品意図が伝わりにくいところ | どこのお店の動画なのかが、最後まで分からない |
| 3 | 人によって好みが分かれるところ | 色の強さ、テロップの書体 |

- 曲は替えないでください（提出した音楽クレジットと合わなくなります）
- まだ提出していない人は、【講評まとめ】でほかの人の作品への講評を読み、自分の動画に当てはまるところを直しながら仕上げてください

# よくある講評と、直し方

直す前に、`yokocho_v2` を右クリック ＞ **複製** して名前を `yokocho_v3` にし、こちらを直します

<div class="small">

| 講評 | 直し方 | 第7回 |
|---|---|---|
| テロップが読みにくい | 大きさを 70〜90px にし、境界線（6〜10px）か背景を付けます | P13 |
| テロップが下や右端で隠れる | ガイド画像の「文字はここ」のあたりへ動かします | P13 |
| テロップがすぐ消える | 文字数 ÷ 4 秒（短くても2秒）出しておきます | P13 |
| 曲が大きすぎる | 曲のレベルを下げ、ピークが -6dB を超えないようにします | P14 |
| 終わり方が急 | 曲の終わりに、クロスフェードの **コンスタントパワー** を1秒付けます | P14 |
| テンポが遅い | 1カットを2〜4秒にし、曲の小節の頭で切り替えます | P12 |
| 色が強い、商品の色が変 | Lumetri カラーの値を小さくします | P26、P27 |
| 人の顔が見える | スタンプかモザイクで隠します | P22〜P24 |

</div>

# 直したら、書き出してスマホで確かめましょう

1. ガイド画像のトラックの **目のアイコンをオフ** にします
2. 動画の終わりより後ろに、曲やガイド画像のクリップが残っていないか見ます
3. `yokocho_v3` を選び、画面上の **書き出し** を押して、形式 **H.264**、プリセット **ソースに一致（アダプティブ高ビットレート）** にします
4. 概要の欄で **1080×1920** になっているか確かめます
5. 保存先は `05_yokocho/export/`、ファイル名は提出したときと同じ `学籍番号_氏名_yokocho.mp4` にします。同じ名前のファイルがあると表示されたら、置き換えてかまいません（提出した動画は、提出フォルダに残っています）
6. 自分のスマホに送り、縦にして最後まで再生して、直したところを確かめます

# 納品のしかた（Googleドライブ）

1. Classroomの授業タブで「第8週資料」を開き、【納品場所】のリンクを開きます
2. 書き出した `学籍番号_氏名_yokocho.mp4` を、フォルダの中へドラッグしてアップロードします
3. フォルダに、自分の mp4 が入っているのを確かめます

- 締切は **11/20（金）2講時の終わり** です
- 直すところがなかった人も、提出した mp4 を納品フォルダに入れてください
- まだ提出していない人は、提出フォルダに mp4 とGoogleドキュメントを入れてから（第7回のスライドの P16〜P19）、同じ mp4 を納品フォルダにも入れてください
- 納品するのは mp4 だけです。作品意図と音楽クレジットは、提出したGoogleドキュメントを使います
- 出し直すときは、前の mp4 を削除してからアップロードしてください
- 納品フォルダはクラス全員で共通です。ほかの人のファイルは、開いて見るだけにしてください

# 納品前のチェックリスト

| 見るところ | 確かめること |
|---|---|
| 長さと大きさ | 15〜30秒で、書き出しの概要が 1080×1920 になっているか |
| 画面 | ガイド画像が映っていないか。最後に黒い画面や、灰色のカラーマットの穴が残っていないか |
| テロップ | 下のキャプションや右端のアイコンにかからず、スマホで読める大きさと長さか |
| 人 | 人が写っているところを隠したか（自分で、出てもよい場合を除く） |
| 音 | ピークが -6dB を超えていないか。曲の終わりがフェードになっているか |
| 曲 | 提出したときと同じ曲か |
| スマホ | スマホに送り、縦にして最後まで再生したか |
| ファイル名と場所 | `学籍番号_氏名_yokocho.mp4` で、納品フォルダに入っているか |
