# 制作補助①
## ラフ構成案（台割）

---

# 台割＝設定資料集の設計図

- **台割**：どのページに何を載せるかの一覧
- いきなり清書しない。**まず構成を決める**
- 台割が決まると **「⑭までに何を作ればいいか」が見える**

### 推奨台割ひな型（そのまま使ってOK）

表紙／ストーリー1p／世界観×2p／主要キャラ×2〜3p／短編動画1p／まとめ

---

# AIと壁打ちで台割を作る

```
# 依頼
アニメ／ゲームの設定資料集の台割（ページ構成）を一緒に考えてください

# 作品の情報
- タイトル・ジャンル：◯◯
- ストーリー：◯◯（あらすじ1〜2行）
- 世界観：◯◯（1〜2行）
- 主要キャラ：◯◯（人数と一言ずつ）

# 条件
- 全8ページ前後。「ストーリー」「世界観」「主要キャラ」「短編動画」を必ず含める
- 手持ち素材：キャラ三面図・ポーズ／背景／修正済み画像

# 出力
- ページごとに「載せるもの」を1行で
- 手持ち素材で足りないものがあれば指摘して
```

---

# 記入例（サンプルデータ『竜灯の旅』）

```
# 作品の情報
- タイトル・ジャンル：『竜灯の旅』／王道ファンタジー（アニメ想定）
- ストーリー：夜を照らす「竜灯」が消えはじめた世界。見習い灯守の少女リコが、
  相棒の小竜ポポと「はじまりの灯台」を目指して旅に出る
- 世界観：灯りはすべて竜がもたらす世界。中世ヨーロッパ風の港町、竜の形の街灯
- 主要キャラ：リコ（14歳・見習い灯守）／ポポ（手のひらサイズの発光する小竜）
```

→ このくらいの粒度でOK。ここからAIと往復する
