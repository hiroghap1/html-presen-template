## 配色パターン

# AIと配色を検討する

世界観・キャラの色を **候補から選ぶ**

```
# 依頼
この世界観に合う配色パターンを3案ください

# 世界観
◯◯（第10回の世界観テキストを貼る）

# 出力
- 各案：メイン／サブ／アクセントの色（HEX）＋雰囲気の説明
- それぞれ、どんな作品に向くかの理由
```

→ 複数案を出させて、**理由を言語化して選ぶ**

---

# Adobe Color で「自分の配色」に

- AIが出した候補（HEX）を入れて **パレット化・保存**
- 類似・補色などのルールで **微調整**
- 資料集全体で同じパレットを使う → **統一感** が出る

→ 「AIに決めさせる」のではなく
　「**候補を広げて、自分が選ぶ**」＝相棒の使い方

---

# 短編動画の作り方

1. **シナリオ3行**：誰が／どこで／何をする
2. プロンプトを **AIに書かせる**
3. **Fireflyの動画生成** で **モデル：Kling 3.0** を選んで生成

→ **最初と最後の場面を静止画で生成して「フレーム」に指定**
→ 動画のクオリティとシナリオを自分でコントロール

---

# 設定レシピ（Kling 3.0）

| 項目 | 値 |
|---|---|
| モデル | **Kling 3.0** |
| 解像度／縦横比 | 1080p／**縦長（9:16）** |
| フレーム毎秒／時間 | 24 FPS／**15秒** |
| 音声 | オフ |
| **フレーム** | **最初・最後の画像を指定** |

⚠️ **375クレジット／本**。フレーム＋プロンプトを整えてから、**原則1〜2本**で決める（クレジットと相談）

---

# 動画プロンプトをAIに書かせる

```
# 依頼
Kling 3.0（Fireflyの動画生成）用の動画プロンプトを書いてください

# シナリオ
- 誰が：◯◯
- どこで：◯◯
- 何をする：◯◯

# 条件
- 15秒・縦長（9:16）
- 最初のフレーム：添付画像A（キャラの設定画）
- 最後のフレーム：添付画像B（背景・引きの1枚）
- カメラワークと動きの指示も入れて
```
