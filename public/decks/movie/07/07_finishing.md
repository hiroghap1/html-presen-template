# 作業2 絵コンテの順にカットを並べ直す

1. 絵コンテを横に置き、1コマ目から順に、タイムラインのカットの順番を合わせる
2. カットを動かすときは、<kbd>Ctrl</kbd> を押しながらクリップをドラッグし、つなぎ目で離す。間に割り込み、後ろのカットがずれる
3. 動かしたあとに元の場所にできた隙間は、隙間を右クリック ＞ **リップル削除** で詰める
4. 足りないカットは、`1_使う` か `2_予備` のビンからダブルクリックしてソースモニターで開き、<kbd>I</kbd> と <kbd>O</kbd> を打ってから <kbd>,</kbd>（インサート）で入れる
5. 使わないカットは、選んで <kbd>Shift</kbd>+<kbd>Delete</kbd> を押す（リップル削除。後ろのカットが詰まる）

> 絵コンテにあるのに素材がないカットは、撮り足すか、予備のカットで置き換えるかを自分で決める

# 作業2 カットの長さを曲の小節に合わせる

1. タイムラインの左上の **スナップ**（磁石のアイコン、<kbd>S</kbd>）をオンにする
2. 1カットが **2〜4秒** になるように、1小節に1カットか、2小節に1カットにする

| 1小節の長さ | 1カットの長さ |
|---|---|
| 2秒より短い | 2小節に1カット |
| 2〜4秒 | 1小節に1カット（短く感じたら2小節） |

3. クリップの終わりを、マーカーまでドラッグして縮め、できた隙間は右クリック ＞ **リップル削除**
4. 全体の長さを **15〜30秒** にし、曲は最後のカットの終わりで切る

> 曲を短くするときは、小節の頭で切る。曲を自動で組み直して長さを合わせる [リミックスツール](https://helpx.adobe.com/jp/premiere/desktop/add-audio-effects/apply-audio-effects/remix-audio-in-premiere.html) もある（使うとマーカーとずれるので、打ち直す）

# 作業4 音を整える

| トラック | すること | 目安 |
|---|---|---|
| A2 曲 | 音量を下げる | 再生してピークが **-6dB** を超えない（レベル -6〜-12dB） |

# 作業5 色 ①：調整レイヤーを作って V2 に置く

**調整レイヤー** は、下のトラックの映像に同じ色をまとめてかける、透明なクリップです。1か所で設定すれば、全部のカットの色がそろいます。

1. プロジェクトパネルを選んでから、メニューの ファイル ＞ 新規 ＞ **調整レイヤー** を選び、出てきた画面はそのまま **OK** を押す（大きさはシーケンスと同じになる）
2. プロジェクトパネルにできた「調整レイヤー」を、タイムラインの **V2** の先頭へドラッグする
3. 調整レイヤーの終わりをドラッグして、動画の終わりまで伸ばす
4. エフェクトパネルの検索欄に「Lumetri」と打ち、**Lumetri カラー** を V2 の調整レイヤーにドラッグする

> 色の値は次のページ（<a href="#15" data-to="w5b">P15</a>）

# 作業5 色 ②：Lumetri カラーの値

V2 の調整レイヤーを選び、エフェクトコントロールの **Lumetri カラー** を開いて、次の値にする

| 場所 | 項目 | 値 | 変わること |
|---|---|---|---|
| 基本補正 ＞ カラー | 色温度 | **+20** | 全体が黄色っぽく、暖かくなる |
| 基本補正 ＞ カラー | 彩度 | **80** | 色が少し落ち着く |
| クリエイティブ ＞ 調整 | 色あせたフィルム | **30** | 黒い部分が薄くなり、古い写真に近づく |
| ビネット | 適用量 | **-1.5** | 画面の四隅が少し暗くなる |

- 値は目安です。自分の素材で強すぎると感じたら、数字を小さくする
- 駄菓子やおもちゃの色が変わりすぎていないか、商品が写っているカットで確かめる

公式の説明：[Premiere でベーシックカラー補正を調整する](https://helpx.adobe.com/jp/premiere/desktop/correct-color/color-correction-fundamentals/basic-color-correction-options.html)

# 作業5 色 ③：色を付ける前と比べる

1. タイムラインの V2 の左にある **目のアイコン** を押すと、色を付ける前の映像になる。もう一度押すと元に戻る

# 作業6 モザイクで隠す

<div class="small">

1. 人が写っているクリップ（V1）を選ぶ
2. エフェクトパネルの検索欄に「モザイク」と打ち、**モザイク** をクリップにドラッグする（「モザイク (レガシー)」ではないほう）
3. エフェクトコントロールで、水平ブロック **30**、垂直ブロック **53** にする。この時点では、画面全体がモザイクになる
4. エフェクトコントロールで「モザイク」の行をクリックして選んだまま、ツールパネルの **楕円形マスクツール** で、プログラムモニターの顔を囲む。モザイクが顔の部分だけになる
5. 人が動くときは、エフェクトコントロールのマスクにある **選択したマスクを順方向にトラック**（右向きの三角のボタン）を押す
6. 再生して、顔からモザイクが外れるコマがないか確かめる。外れたコマでは、マスクをドラッグして直す

- マスクが「割り当てられていないマスク」に入ったときは、そのマスクをエフェクトコントロールの「モザイク」の上へドラッグする
- 顔が分かるときは、ブロックの数を減らして粗くする
- 公式の説明：[マスクのトラッキング](https://helpx.adobe.com/jp/premiere/desktop/add-video-effects/create-masks-and-composites/track-masks.html)、[オブジェクトマスク](https://helpx.adobe.com/jp/premiere-pro/using/object-masking.html)（人を自動で選んで追いかける機能。PCによっては使えない）

</div>
