# 作業2 絵コンテの順にカットを並べ直す

1. 絵コンテを横に置き、1コマ目から順に、タイムラインのカットの順番を合わせます
2. カットを動かすときは、<kbd>Ctrl</kbd> を押しながらクリップをドラッグし、つなぎ目で離します。間に割り込み、後ろのカットがずれます
3. 動かしたあとに元の場所にできた隙間は、隙間を右クリック ＞ **リップル削除** で詰めます
4. 足りないカットは、`1_使う` か `2_予備` のビンからダブルクリックしてソースモニターで開き、<kbd>I</kbd> と <kbd>O</kbd> を打ってから <kbd>,</kbd>（インサート）で入れます
5. 使わないカットは、選んで <kbd>Shift</kbd>+<kbd>Delete</kbd> を押します（リップル削除なので、後ろのカットが詰まります）

> 絵コンテにあるのに素材がないカットは、撮り足すか、予備のカットで置き換えるかを自分で決めてください

# 作業2 カットの長さを曲の小節に合わせる

1. タイムラインの左上の **スナップ**（磁石のアイコン、<kbd>S</kbd>）をオンにします
2. 1カットが **2〜4秒** になるように、1小節に1カットか、2小節に1カットにします

| 1小節の長さ | 1カットの長さ |
|---|---|
| 2秒より短い | 2小節に1カット |
| 2〜4秒 | 1小節に1カット（短く感じたら2小節） |

3. クリップの終わりをマーカーまでドラッグして縮め、できた隙間は右クリック ＞ **リップル削除** で詰めます
4. 全体の長さを **15〜30秒** にし、曲は最後のカットの終わりで切ります

> 曲を短くするときは、小節の頭で切ります。曲を自動で組み直して長さを合わせる [リミックスツール](https://helpx.adobe.com/jp/premiere/desktop/add-audio-effects/apply-audio-effects/remix-audio-in-premiere.html) もあります（使うとマーカーとずれるので、打ち直してください）

# 作業3 テロップを入れる

| 入れるもの | 例 |
|---|---|
| 店名 | 京都・二条の／昭和レトロ横丁 |

# 作業4 音を整える

| トラック | すること | 目安 |
|---|---|---|
| A2 曲 | 音量を下げます | ピークが **-6dB** を超えない程度（レベル -6〜-12dB） |
| A2 曲 | 終わりをフェードにします | クロスフェードの **コンスタントパワー** を **1秒** |
| A3 効果音 | テロップが出る瞬間などに置きます | 30秒で **4か所まで** |
| A1 スマホの音 | 曲の邪魔にならない大きさまで下げます | いらなければ消してかまいません |

<div class="small">

- 音量：クリップを選び、エフェクトコントロール ＞ オーディオ ＞ ボリューム ＞ **レベル**
- ピーク：再生しながら、タイムラインの右のオーディオメーターを見ます
- フェード：エフェクト ＞ オーディオトランジション ＞ クロスフェード ＞ **コンスタントパワー** を曲の終わりにドラッグし、ダブルクリックして1秒にします
- 映像を残して音だけ消す：<kbd>Alt</kbd> を押しながら音のクリップをクリックして、<kbd>Delete</kbd> を押します

</div>

> 効果音は、第6回の素材の `audio/se_ポン.wav` を使ってかまいません。画面写真つきの手順は、第6回のスライドの P13〜P14 にあります （<a href="?deck=decks/movie/06/06_handson_music.md" target="_blank">第6回のスライドを開く</a>）

# 曲の利用条件を、もう一度確かめましょう

# 人を隠す ③：モザイクで隠す

<div class="small">

1. 人が写っているクリップ（V1）を選びます
2. エフェクトパネルの検索欄に「モザイク」と打ち、**モザイク** をクリップにドラッグします（「モザイク (レガシー)」ではないほうです）
3. エフェクトコントロールで、水平ブロック **30**、垂直ブロック **53** にします。この時点では、画面全体がモザイクになります
4. エフェクトコントロールで「モザイク」の行をクリックして選んだまま、ツールパネルの **楕円形マスクツール** で、プログラムモニターの顔を囲みます。モザイクが顔の部分だけになります
5. 人が動くときは、エフェクトコントロールのマスクにある **選択したマスクを順方向にトラック**（右向きの三角のボタン）を押します

- 顔が分かるときは、ブロックの数を減らして粗くしてください
- 公式の説明：[マスクのトラッキング](https://helpx.adobe.com/jp/premiere/desktop/add-video-effects/create-masks-and-composites/track-masks.html)、[オブジェクトマスク](https://helpx.adobe.com/jp/premiere-pro/using/object-masking.html)（人を自動で選んで追いかける機能です。PCによっては使えません）

# 色 ①：調整レイヤーを作って V2 に置く

映像を昭和の写真のような暖かい色にしたいときに行います（素材の色のままでよければ、行わなくてかまいません）

**調整レイヤー** は、下のトラックの映像に同じ色をまとめてかける、透明なクリップです。1か所で設定すれば、全部のカットの色がそろいます。

1. プロジェクトパネルを選んでから、メニューの ファイル ＞ 新規 ＞ **調整レイヤー** を選び、出てきた画面はそのまま **OK** を押します（大きさはシーケンスと同じになります）
2. プロジェクトパネルにできた「調整レイヤー」を、タイムラインの **V2** の先頭へドラッグします
3. 調整レイヤーの終わりをドラッグして、動画の終わりまで伸ばします
4. エフェクトパネルの検索欄に「Lumetri」と打ち、**Lumetri カラー** を V2 の調整レイヤーにドラッグします

# 色 ②：Lumetri カラーの値

V2 の調整レイヤーを選び、エフェクトコントロールの **Lumetri カラー** を開いて、次の値にします

| 場所 | 項目 | 値 | 変わること |
|---|---|---|---|
| 基本補正 ＞ カラー | 色温度 | **+20** | 全体が黄色っぽく、暖かくなります |
| 基本補正 ＞ カラー | 彩度 | **80** | 色が少し落ち着きます |
| クリエイティブ ＞ 調整 | 色あせたフィルム | **30** | 黒い部分が薄くなり、古い写真に近づきます |
| ビネット | 適用量 | **-1.5** | 画面の四隅が少し暗くなります |

- 値は目安です。自分の素材で強すぎると感じたら、数字を小さくしてください
- 駄菓子やおもちゃの色が変わりすぎていないか、商品が写っているカットで確かめてください

公式の説明：[Premiere でベーシックカラー補正を調整する](https://helpx.adobe.com/jp/premiere/desktop/correct-color/color-correction-fundamentals/basic-color-correction-options.html)
